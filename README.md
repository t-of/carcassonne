# carcassonne — 身内で交代して遊ぶタイル配置

カルカソンヌ基本セットを1台で交代して遊ぶ試作

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/carcassonne/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

2〜5 人、1 台の画面を交代して遊ぶカルカソンヌ（基本セット・拡張なし）の試作。

1. 人数を選ぶと、開始タイルが盤の中心に置かれる。
2. 山札からタイルを 1 枚引く。「回す」で向きを変え、黄色く光る置ける場所をタップして置く。
   どこにも置けないタイルは自動で捨てて次を引く。
3. 置いたタイルの都市・道・修道院・草原のどれかに駒を置ける（つながった先に他人の駒がいれば置けない）。
   置かないなら「駒を置かない」。
4. 都市・道が完成する、修道院の周り 8 マスが埋まると、その場で採点して駒が戻る。
5. 山札がなくなったら、残りの都市・道・修道院・草原をまとめて採点し、順位を出す。

盤はドラッグ（タッチ）で動かし、ホイール／ピンチでズームする。得点は、道 1 点/枚、都市は完成 2 点/枚＋紋章 2 点
（未完成は最後に 1 点/枚＋紋章 1 点）、修道院は完成 9 点（未完成は最後に 1＋周りの枚数）、
草原は最後だけ接する完成した都市 1 つにつき 3 点。駒が最多の人が得点し、同数なら全員が満点。

途中の状態は端末に自動で保存され、リロードすると「つづきから」で再開できる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
